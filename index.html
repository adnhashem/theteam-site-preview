ملاحظات التنفيذ

  • الحركة ظهور فقط — عبر animation-timeline: view() بـ CSS أصلي، صفر JavaScript، تعمل على compositor thread.
  • معطَّلة بالطريقة الصحيحة — ملفوفة بـ @media not (prefers-reduced-motion)، لا بتصفير المدة (تصفير المدة لا يوقف حركة السكرول إطلاقاً).
  • زر «إيقاف الحركة» — مطلب WCAG 2.3.3: بديل داخل الموقع لمن لم يضبط إعداد النظام. جرّبه.
  • كل الألوان محسوبة — أدنى تباين نص 5.65:1، والنص الأساسي 17.37:1 (AAA).
  • الأرقام غربية (120، 94%) داخل نص عربي — معيار الخليج، لا الأرقام الشرقية.
  • خصائص منطقية بالكامل (inline-start, block-end) — الصفحة تنقلب للإنجليزية بلا تعديل CSS واحد.
  • الأرقام وأسماء الأعمال افتراضية لأغراض العرض.
